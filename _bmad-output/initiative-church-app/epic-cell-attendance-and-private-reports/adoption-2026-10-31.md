## Reproduce the planning checks

From a checkout of the candidate, with uv installed:

```bash
root="$(pwd)"
skill="$root/.agents/skills/bmad-ticket"
tree="$root/_bmad-output/initiative-church-app"
uv run "$root/_bmad/scripts/resolve_config.py" --project-root "$root" --key core.output_folder --key core.active_initiative
uv run "$skill/scripts/tickets.py" --project-root "$root" status "$tree"
uv run "$skill/scripts/tickets.py" --project-root "$root" status "$tree/epic-cell-attendance-and-private-reports"
uv run "$skill/scripts/tickets.py" --project-root "$root" next "$tree/epic-cell-attendance-and-private-reports"
```

These commands inspect planning state. They do not deploy, send notifications, change the hosted database or mark acceptance complete.
