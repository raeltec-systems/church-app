# World English Bible source package

The bundled WEB text is copied from eBible.org's official VPL package:

- Package: <https://ebible.org/Scriptures/engwebp_vpl.zip>
- Edition details: <https://ebible.org/details.php?id=engwebp>
- Rights statement: <https://ebible.org/engwebp/copyright.htm>

eBible.org states that the World English Bible is public domain and may be
copied and distributed. The name is a trademark; retain it only for a faithful
copy of the official text. The package builder validates all 66 books and
1,189 chapters against the trusted verse manifest before producing the bundled
asset. It also checks the five empty verse slots from the source package so
they remain visibly omitted rather than receiving invented text.

Production publication and offline use still follow the app's separate rights
review and promotion process.
